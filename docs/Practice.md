# Основное описание проекта


## Forest Ranger

**Жанр:** Мобильное стелс-приключение

**Движок:** Unity 

**Платформы:**  Android, IOS


## Концепт игры

 После появления в заповеднике банды браконьеров «Чёрные следопыты» лес начинает меняться. Главному герою предстоит защитить наследие своего отца, остановить захват территории и раскрыть тайну аномалии «Тропа Древних», которую браконьеры хотят превратить в источник прибыли.


## Цель проекта

Создание мобильного игрового продукта с возможностью выхода на мобильный игровой рынок.

### Проблема, на решение которой направлен проект

Продвижение игровой индустрии и привлечение внимания к молодым разработчикам с целью обеспечить их необходимыми ресурсами для разработки конкурентно-способных продуктов для игрового рынка.

### Основные механики

*-Исследование леса
*-Фотографирование природы
*-Лечение животных
*-Сбор трав
*-Итерактивное окружение
*-Атмосферный нарратив

### Нарратив

Главный герой противостоит банде браконьеров «Чёрные следопыты». Их основная задача — завладеть заповедником отца и открыть свой охотничий клуб, а также продать доступ к аномалии «Тропа Древних», которая является главной тайной леса.


## Текущий статус

Демо версия с основными механиками
